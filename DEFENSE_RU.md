# Подготовка к защите Assignment 5

Проект состоит из четырёх HTML-страниц. У каждой страницы общий CSS, файл с данными студента и свой JavaScript. Атрибут `defer` откладывает выполнение скриптов до разбора HTML и сохраняет порядок подключения: сначала `student.js`, затем скрипт страницы.

## Как показать проект

1. Откройте `index.html`: появится `Hello, JavaScript World!`. Закройте окно и откройте консоль браузера: там имя, группа, типы переменных и результаты вычислений.
2. На странице DOM нажмите Change text, Change background и Change font size. Добавьте два элемента и удалите последний.
3. На странице Events наведите указатель на блок и уберите его. Введите текст. Проверьте четыре операции калькулятора, пустой ввод и деление на ноль.
4. На странице To-do добавьте две задачи. Отметьте одну выполненной, снимите отметку, удалите задачу. Перезагрузите страницу: список очистится.

## Задания 0 и 1

`console.log()` выводит данные в консоль, `alert()` открывает диалог браузера. Функция `showWelcome()` вызывается при загрузке и по нажатию кнопки.

В `runExamples()` переменная `language` содержит строку, `a` и `b` — числа, `isLearning` — логическое значение. Оператор `typeof` показывает тип. При работе с числами `+` выполняет сложение, а со строками — конкатенацию. Поэтому в выражении `"12 + 4 = " + (a + b)` нужны скобки: сначала вычисляется сумма чисел.

`const` запрещает повторно присваивать переменной другое значение. `let` используется там, где значение меняется: например, счётчик идентификаторов. Массив или объект, объявленный через `const`, всё равно может менять содержимое.

## Задания 2–4

DOM — объектное представление HTML-документа. `document.getElementById()` находит элемент по его идентификатору. `addEventListener("click", ...)` связывает нажатие с функцией-обработчиком.

`textContent` заменяет текст абзаца. Свойства `style.backgroundColor` и `style.fontSize` меняют оформление. Индекс цвета циклически увеличивается с помощью остатка от деления `%`. Логическая переменная `largeText` переключает размер между 16 и 24 пикселями.

`document.createElement("li")` создаёт элемент, `appendChild()` вставляет его в список. `lastElementChild` находит последний элемент, `remove()` удаляет его. Проверка существования последнего элемента защищает от ошибки при пустом списке.

## Задания 5 и 6

`mouseover` срабатывает при наведении мыши, `mouseout` — когда мышь выходит из блока. Дополнительно `focus` и `blur` дают похожую обратную связь при работе клавиатурой.

`keyup` срабатывает при отпускании клавиши. Обработчик берёт `input.value` и записывает его в `textContent` абзаца. Дополнительное событие `input` поддерживает вставку мышью и экранные клавиатуры.

## Задание 7

Калькулятор обрабатывает событие `submit` формы. `event.preventDefault()` отменяет обычную отправку формы и перезагрузку страницы. `valueAsNumber` читает число из поля. Если число получить нельзя, результатом будет `NaN`.

`Number.isFinite()` проверяет, что значение — конечное число. `switch` выбирает одну из четырёх операций. Деление на ноль проверяется отдельно. `toPrecision(12)` ограничивает число значащих цифр при отображении: например, скрывает длинный хвост у результата `0.1 + 0.2`. Это форматирование для учебного калькулятора, а не точная десятичная арифметика.

## Задание 8

`tasks` — массив объектов вида `{ id, title, description, completed }`. `id` уникален даже при одинаковых названиях задач. `trim()` убирает пробелы по краям и позволяет отклонить пустое название.

Добавление использует `push()`. `renderTasks()` очищает список через `replaceChildren()` и создаёт элементы из массива. Переключение checkbox меняет `completed`; `classList.toggle()` включает CSS-класс, который задаёт `text-decoration: line-through`. Удаление использует `filter()`, оставляя объекты с другими идентификаторами.

Обработчики сохраняют доступ к соответствующему объекту `task`: это пример замыкания. При повторном выводе списка элементы и обработчики создаются заново. При переключении checkbox обновляется существующий элемент, поэтому фокус клавиатуры не теряется.

Пользовательский текст вставляется через `textContent`, а не `innerHTML`. Поэтому введённые HTML-теги остаются текстом. Данные живут только в оперативной памяти страницы и исчезают после её перезагрузки.

## Что полезно уметь изменить самостоятельно

- Изменить текст приветствия и значения `a` и `b`.
- Добавить цвет в массив `colors`.
- Добавить кнопку очистки списка с помощью `replaceChildren()` и обновить счётчик.
- Добавить операцию остатка от деления в `<select>` и соответствующий `case` в калькуляторе.
- Добавить фильтр незавершённых задач через `tasks.filter(task => !task.completed)`.
